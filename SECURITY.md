# Security Policy

## Supported Versions

| Version | Supported |
|:---|:---|
| 1.0.x | ✅ |
| < 1.0 | ❌ |

## Reporting a Vulnerability

If you discover a security issue, please open an issue in this repository or contact the maintainer directly.

We take all reports seriously and will respond within 48 hours.

## Scope

This tool uses kernel-level input simulation (Interception driver). It does not:
- Inject DLLs into game processes
- Modify game memory
- Access network resources
- Collect telemetry

If you believe any of these are violated, please report immediately.
