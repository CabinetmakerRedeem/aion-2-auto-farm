# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] — October 2026

### Added
- Auto-Farm Kina (Pilgrim's Rest, Corridor routes)
- Auto-Questing for daily and regional quests
- Resource Gathering with computer vision
- Auto-Combat with class-specific skill rotations
- Anti-Stuck failsafe system
- Clean UI overlay
- Native C++ build, 2.0 MB, no runtime dependencies

### Security
- No telemetry, no ads, no bundled software
- External input simulation only
